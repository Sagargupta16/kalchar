# UI review and improvements

Reviewed and updated the local site on 14 September 2026, with integration and PR review on 15 September. One dedicated agent audited each of the 23 public, admin, and recovery pages, working in parallel batches. Shared components were integrated and checked together afterward.

The review covered desktop and phone layouts, light and dark themes, keyboard navigation, touch gestures, form drafts, uploads, pending actions, failures, and recovery.

## Shared design and motion

- Consistent 16px corners on cards, fields, buttons, image plates, and panels; 24px corners on sheets. Pills and circular controls keep their shapes.
- Shared spacing for sections, card content, fields, and action groups. Controls maintain a 44px minimum touch target.
- Softer layered shadows, clear surface depth in both themes, and restrained hover and press feedback.
- Removed the long double-line ornaments, repeated heading rules, quote framing, and oversized footer spacing.
- Adapted the portfolio-react motion approach: a shared 400ms ease-out curve, spring interactions, short staggered reveals, and smooth image transitions.
- Animation stays enabled across operating-system motion preferences, as explicitly requested for this pass.
- Floating controls and sheets use a consistent translucent surface. Large surfaces animate opacity and transforms; backdrop blur stays static.
- Mobile navigation locks background scrolling, contains keyboard focus, closes on route selection or Escape, and restores focus and scroll position.
- Theme controls stay synchronized between desktop, mobile, and admin navigation.

## Comparison with production

Compared the local preview with https://kalchar.co.in/ on 15 September 2026, using matching 1280 × 720 desktop and 390 × 844 phone viewports. Home, artwork browsing and detail, About, Events, Workshops, Custom Orders, Contact, and shared navigation/footer were inspected. Light theme was used for the direct comparison, with the local dark theme checked afterward.

| Measurement | Production | Updated local site |
| --- | --- | --- |
| Desktop hero heading | 72px | About 68px |
| Desktop section headings | 48px | About 40px |
| Phone hero heading | 48px | 44px |
| Phone section headings | 30px | 30px |
| Desktop interior-page headings | 48px | About 44px |
| Desktop footer height | 566px | 304px |
| Phone footer height | 1,070px | 533px |
| Phone home-contact section height | About 741px | About 640px |
| Phone gallery filter labels | 12px | 14px, with 44px tap targets |

The updated site uses Inter for body text and controls while retaining Cormorant Garamond for display headings. Body text stays around 16px on phones. The gallery's short “Artwork” heading replaces the longer production title, and search, availability, and style filters remain distinct. Home contact details are readable without clipped values. The inspected pages have no horizontal overflow.

The comparison found one mobile regression: the featured painting appeared before the introduction and main actions, pushing those actions below the first screen. The introduction and actions now precede the painting on phones; the desktop composition stays the same. At 390px width, both actions are fully visible within the first 477px of the page. The corresponding viewport and keyboard-navigation checks follow this reading order.

The artwork-detail comparison also exposed a collapsed image frame. The image decoded successfully, but the shared elevation rule overrode its absolute positioning, leaving a zero-height image. Making the elevation positioning a zero-specificity fallback restores the full frame while keeping hover shadows and ordinary cards unchanged. Existing detail tests now require a visible image whose height matches its frame, covering available, sold, and archive pieces at phone and tablet widths. An independent cascade review found no related issues in other elevation consumers.

Local catalog fixtures differ from production, so event, testimonial, and inventory differences were not treated as design regressions.

## PR review

Three reviewers independently inspected public interactions, admin workflows, and server/data boundaries. Seven actionable findings were corrected before delivery:

- Add destinations now use the same unsaved-draft confirmation as navigation links; cancellation retains the draft and restores focus.
- Global event-photo selections populate the creation form on the current page or after navigation. Photos selected while another event is saving wait for its request to finish.
- A pending artwork action locks other artwork mutations and Undo, preventing dropped requests and misplaced errors.
- Pan limits account for the zoom origin, and existing pan is constrained again when the zoom level changes.
- Changing artwork pages with Back or Forward closes the old detail viewer and releases its scroll lock.
- Artwork and workshop changes invalidate About-page counts.
- Enquiry reply links preserve explicit international phone prefixes.

The artwork-action regressions passed with 76 focused browser checks; the Add workflows passed with 44. Viewer regressions and history checks passed with seven checks against the running preview, and the five new viewer scenarios also passed against the optimized build. These focused counts include existing scenarios rerun around the fixes and are separate from the browser baseline above.
